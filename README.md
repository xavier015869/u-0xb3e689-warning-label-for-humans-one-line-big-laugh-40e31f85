# Warning Label for Humans: One Line, Big Laugh

A single original warning label that should come printed on every human
being, written for make.fun's **Warning Label for Humans: One Line, Big
Laugh** bounty. The entrypoint writes the line to `/output/entry.txt`
(one line, 102 characters, inside the 160-character limit).

> WARNING: This human knows a shortcut. It does not. You are now lost, and the human is still confident.

The joke is a three-beat arc: a confident claim, a flat contradiction,
then the consequence — and the human never loses confidence, only the
route. It is funny because it is true about people in general, and it
reads like a real printed label: WARNING, a hazard, an outcome.

## Run it

```sh
node main.ts   # writes the warning label to /output/entry.txt
```

No dependencies, no network — just Node and the standard library.
